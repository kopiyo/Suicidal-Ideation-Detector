**Suicidal-Ideation-Detector**


A web-based machine learning application that analyzes user-provided text to identify potential suicidal ideas using natural language processing techniques. This is important for early detection and prevention efforts, thus minimizing suicide related death cases. 
An LSTM-based deep learning web application that detects suicidal ideation in tweets.  
Built with Streamlit for Mental Health Awareness.

**Features**

- Detects suicidal ideation in tweet text or uploaded screenshots
- Displays prediction confidence and risk level
- Shows positive intensity using a gauge chart
- Tracks recent analyses with an analytics dashboard
- Includes crisis helplines for Kenya, US, UK, and International users

![Web Interface](Web%20Interface.jpg)

**How to Use**


1. Enter a tweet in the text box **or** upload a screenshot
2. Click **Analyze**
3. View the prediction result, confidence score, and risk level
4. Access crisis helplines directly from the app if needed

The system is built using a machine learning model based on LSTM architecture to analyze the emotional tone of the input text and identify potential suicidal ideation and classifies whether a tweet is negative or positive. The simple and user-friendly design allows for easy interaction and quick analysis.
